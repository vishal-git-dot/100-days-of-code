# Day 85 – Flask Delete Uploaded Files

## 📌 Overview

In this project, I learned how to delete uploaded files in Flask applications.

After learning file uploads and image previews, the next important step is managing uploaded files efficiently.

This feature is commonly used in:

- Social media applications
- Portfolio websites
- CMS platforms
- User profile systems
- Document management systems

In this project:

- Users can upload files
- View uploaded files
- Delete uploaded files
- Manage file storage effectively

## 🛠 What I Did

- Created a file upload system
- Displayed uploaded files
- Added delete functionality
- Removed files from the uploads folder
- Used Flask routes for file deletion
- Improved file management workflow
